A modern, AI-powered Learning Management System built with a premium design system.

```

├── .gemini/

└── pages/
```

## 🚀 Getting Started

Each page in `pages/` is a self-contained HTML file. Simply open any `.html` file in your browser to preview:

```bash
# Open a page directly
start pages/original/login.html
```
